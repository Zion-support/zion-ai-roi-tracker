# 💹 Zion AI ROI Tracker

Track realized ROI of AI & automation initiatives — from promised business case to measured value. Part of the **Zion ITOps AI Suite (Batch 72)**.

## What it does
- Registers AI/automation initiatives with baseline costs and target KPIs
- Measures realized savings/revenue uplift against baselines
- Portfolio dashboard: value delivered, payback, adoption and model cost drift

## Key features
- Value-driver trees linking operational metrics to financial outcomes
- LLM cost tracking (tokens, infra, licenses) vs. benefits
- CFO-ready quarterly value reports
- Feeds incident cost data from [Zion Incident Triage](https://github.com/Zion-support/zion-incident-triage)
